STBM / Smart Tool Box개발 준비 중

STEEL AI HACKATHON · 11.09 — 11.10

공구의 이동을 기록하고,
정비의 흐름을 이어가다.

Smart Tool Box는 QR을 활용해 공구 출납 기록 누락을 줄이고,
사용 현황을 쉽게 파악하기 위한 STBM 팀의 프로젝트입니다.

프로젝트 시작점

로컬 개발 화면

개발 환경을 준비했습니다. 실제 업무 흐름에 맞춰 필요한 기능을 하나씩 정하고 만들어갑니다.

01 / 기록

출납 기록 누락 줄이기

공구가 언제 나가고 돌아오는지 확인할 수 있도록.

02 / 사용자

사용 현황 파악하기

누가 어떤 공구를 사용하는지 알 수 있도록.

03 / 정비

정비 지연 줄이기

파손과 미반납으로 생기는 불편을 줄일 수 있도록.

현재는 프로젝트 안내 화면입니다. QR 스캔·출납·사용자 관리 기능은 아직 구현하지 않았습니다.
